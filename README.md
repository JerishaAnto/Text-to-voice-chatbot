# 🎙️ Text-to-Voice Chatbot

An AI-powered **Text-to-Voice Chatbot** that converts user-entered text into natural-sounding speech. The chatbot provides an interactive interface where users can enter text and listen to the generated voice output.

### ✨ Features

* 📝 Convert text into speech
* 🎙️ Generate voice output instantly
* 💬 Interactive chatbot-style interface
* 🌐 Simple and user-friendly UI
* 🔊 Audio playback for generated speech
* 🐍 Built using Python
* 🚀 Can be run easily in Google Colab

### 🛠️ Technologies Used

* Python
* Text-to-Speech (TTS)
* Gradio
* Google Colab

### 🎯 Project Goal

The goal of this project is to demonstrate how **AI and Natural Language Processing can be used to convert written text into spoken language**, creating a simple and accessible voice-based chatbot.

### 🔮 Future Enhancements

* Support for multiple languages
* Multiple voice options
* Voice input
* Conversation history
* Emotion-based voice generation
* Real-time speech interaction
